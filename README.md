## Project Overview
An interactive Power BI dashboard built on a real-world simulated healthcare dataset (55,500+ patient records).  

The goal is to provide hospital executives with clear insights into:
- Patient volume & revenue trends
- Operational efficiency (length of stay)
- Financial performance

**Live Project (30-Day Challenge)** – Daily updates on progress!

## Day 2 Progress (January 05, 2026) ✅
### Achievements
- Created a dedicated **Calendar table** with Year, Month, Quarter columns
- Established **relationships** between Calendar and healthcare data (using Admission Date)
- Built **Executive Overview page** with 4 KPI cards:
  - Total Patients (latest month)
  - Total Revenue (latest month)
  - Average Length of Stay (latest month)
  - Average Billing Amount (latest month)
- Added **monthly trend lines** in KPI visuals using 'Year-Month' on trend axis
- Used **DATESMTD** function for latest month calculations
- Fixed data type issues (Length of Stay now numeric)
- Clean layout with professional formatting

### Key Learnings
- Importance of proper date table for time intelligence
- How to display latest period values with historical trends
- Troubleshooting common errors (string vs number types)
